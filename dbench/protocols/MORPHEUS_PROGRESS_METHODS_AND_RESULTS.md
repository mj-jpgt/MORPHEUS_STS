## 0. Direct composer: executable capacity run (2026-10-24; running on Lambda)

The direct composer now writes legal two-to-six variable sets from support-patient data with only coarse molecular, morphology and spatial role plus spatial-transform metadata. Candidate identities and query rows are excluded from neural inputs. Its training utility accepts only pre-frozen patient-disjoint, query-labelled episodes; the shared benchmark has a `ComposerSearch` adapter. Focused tests pass (5/5).

The first real-data capacity run was executed on the Lambda A100 using public GSE208253 (12 OSCC Visium sections; 48 released count, coordinate, H&E and scale-factor files validated). It froze patient-disjoint query labels, trained the composer for 250 CUDA steps, then compared held-out query gain with a support-fit screen and random proposals. The one-core cache build was stopped before output and restarted with eight deterministic workers. This is engineering capacity only: temporary frozen RGB/texture descriptors replace H-Optimus/CellViT, and the final exposure-cleared historical registry is not frozen. It is not a biological or historical-rediscovery result.

**Result (negative capacity result, retained).** Four unseen patient-disjoint episodes (targets IGKC, S100A8, S100A9 and S100A7; 96 frozen labelled sets/episode; budget 32) completed. Mean best held-out decomposition gain was **0.0018** for the composer, versus **0.0918** for the fixed support-fit screen and **0.0533** for matched random sets. The screen found the best cached query-gain set in 3/4 episodes; the composer did not. Mean query gain across each method's 32 returned sets was −0.0166 (composer), −0.0183 (screen), and −0.0225 (random), a weak ordering that does not rescue the primary discovery-ranking result. Final composer loss was 5.2469. The checkpoint SHA-256 is `e47262099bdfa9195307ee16e89ab9bd44ff56557c402c7772f7e90c52ae7e64`; the training-receipt SHA-256 is `85510deb0be5e6379e7fc0f716d0495dd9be325d2c370707c540bc8f8bc54e03`. This run validates the data-to-composer-to-held-out-evaluation path and falsifies adequacy of this tiny, identity-free, 8-episode training configuration. It is not evidence for the paper's learned-composer claim.

**Root-cause repair and v2 rerun.** Code inspection identified a direct inference/training mismatch: the original beam ranked completed sets by decoder likelihood, while held-out gain supervised only a separate value head. The decoder was also trained to reproduce high- and low-value cached sets equally, and cache indices were never order-rotated despite the stated intention. This means the original proposal route learned set frequency, not scientific value. The repair (a) ranks completed sets by predicted patient-disjoint decomposition/general utility minus predicted uncertainty, (b) trains the decoder with a gain-weighted ranking loss plus gain-weighted sequence loss, (c) rotates the sequential route every optimisation step, and (d) changes the support-screen comparator from in-sample fit to nested patient-grouped support CV. A contract test deliberately makes decoder likelihood oppose predicted utility and verifies that the composer still returns the higher-utility set; the focused remote test suite passes 5/5.

**v2 result and strictly matched-catalogue check.** The repaired run completed on the Lambda A100 with 24 patient-disjoint episodes (8 targets × 3 folds), 16 train / 8 held-out episodes and 1,200 CUDA steps. When each method may return its own 32 legal relations, mean best query decomposition gain is 0.06763 (composer), 0.07262 (screen), and 0.04500 (random); mean returned-set gain is 0.00872, −0.01563, and −0.02568, respectively. Those quantities use different candidate universes and are therefore diagnostic only, not a head-to-head result. The frozen checkpoint was then evaluated by ranking the **same 96 cached legal relations** as the nested-CV support screen. Composer best gain is 0.07439 versus 0.07262 for the screen (paired difference +0.00177; 95% patient-episode bootstrap CI −0.00052 to +0.00524; 3 wins / 4 ties / 1 loss); mean gain across its selected lists is −0.01742 versus −0.01563 (difference −0.00179; CI −0.01033 to +0.00573; 3 wins / 0 ties / 5 losses). Thus the repair fixes a real implementation error and yields near-parity on this deliberately limited capacity task, but it does **not** establish a neural-composer advantage. This task remains engineering-only: it has hand-crafted image descriptors, a polynomial relation family, eight targets and one study. The next valid test is the frozen-view, multi-study task from `learned_search_v02.md`, with H-Optimus/CellViT-derived views, the actual random-feature relation family, a structured candidate catalogue and the same candidate universe for all rankers.

**Real-task composer v04 → v04.1 (2026-10-24; metric repair and clean rerun active).** The next experiment replaces the surrogate with an immutable cache built from actual patient-disjoint HEST episodes. Each episode uses frozen RNA, H-Optimus morphology-centre and available CellViT views; a support-only, modality-balanced variance shortlist; and one deterministic shared catalogue of legal 2-, 3- and 4-variable sets. Each set is labelled once with query-side `B_nuis`, strict `B_known`, and a higher-order gain relative to the strongest same-family two-block proper-subset decomposition. All rankers must rank this exact catalogue. The cache builder rejects episodes without at least two frozen measurement modalities, records support/query receipt hashes, forbids replacement of existing cache entries, and writes a progress receipt after every episode. The neural value path adds only identity-free support-side joint statistics of selected variable products (degrees 2–4); the original decoder remains a traversal mechanism and cannot determine final scientific priority. Eleven focused contracts pass remotely, including deterministic catalogue replay, support-only shortlist invariance, legality, fixed-catalogue ranking, patient separation, interaction-path gradients, and the no-relation comparator rule. A two-episode real HEST preflight completed (HER2 morphology target `morph:k50`; lymph-node IDC target `morph:k27`; 3,600/1,200 and 1,200/1,200 support/query rows respectively) with all three query labels. It is a pipeline preflight, not a paper metric. The immutable meta-training cache is frozen at **48/48 episodes** (five paired HEST source studies; 26 molecular and 22 morphology targets; 160 support-selected variables and 384 shared catalogue sets per episode; no skipped episodes). The separate kidney-injury development cache is frozen at **24/24 episodes** under the same settings and is never used for training.

**Invalid v04 result (retained for audit; not evidence).** The first completed v04 run initially appeared to beat the screen on `B_decomp` (mean best difference +0.3473; bootstrap interval +0.0022 to +0.9943) while losing clearly on `B_known` (−0.0171; interval −0.0300 to −0.0075). Inspection showed this was invalid: one SLC14A1 catalogue set had full `B_nuis = −0.0053`, but its lower-order comparator had failed at approximately −7.404, yielding an artificial `B_decomp = +7.3985`. The correct scientific comparator includes the null/no-relation baseline, so higher-order gain is now `B_nuis(full) − max(0, B_nuis(best proper-subset decomposition))`. This ensures a negative full relation can never appear synergistic merely because a lower-order fit generalizes even worse. The old v04 cache and checkpoint are preserved but excluded from interpretation. New **v04.1** caches were derived algebraically from the frozen labels without opening any raw query row, preserving every candidate catalogue and patient split; all 48 meta-training and 24 development episodes were repaired, and the maximum remaining development higher-order label is 0.1091. The clean v04.1 rerun is active with the same 2,000 CUDA steps, 48 labels/step, budget 32, and identical support-screen comparator. No neural advantage is claimed pending that result.

**v04.1 corrected result (negative for the neural-composer claim).** The rerun completed on the same 24 kidney development episodes. The composer has a small, uncertain advantage only in the *single best* repaired higher-order set per episode: mean difference in best `B_decomp` **+0.00500** (95% bootstrap CI **−0.00129 to +0.01518**; 10 wins / 3 ties / 11 losses). It does not improve list quality: mean selected-set `B_decomp` difference **−0.00011** (CI **−0.00066 to +0.00044**; 12 / 0 / 12), and `B_decomp` NDCG difference **−0.0094** (CI **−0.0635 to +0.0434**). It loses decisively on the broad, clinically relevant `B_known` objective: best-set difference **−0.01735** (CI **−0.02838 to −0.00851**; 0 / 3 / 21), mean-list difference **−0.04620** (CI **−0.08526 to −0.01508**; 2 / 0 / 22), and NDCG difference **−0.5117** (CI **−0.5974 to −0.4198**; 0 / 0 / 24). The neural predicted-utility Spearman correlation is only **0.0665**. Thus the v04.1 direct composer does not earn a paper-facing superiority claim. The correct conclusion is that the prior large `B_decomp` result was a metric artefact and the repaired architecture is currently noncompetitive with the support-fit screen on this fixed-catalogue real-HEST development task.

Conventions. "Spot" = one Visium or legacy ST measurement location with its H&E patch. "Patient" = the unit of replication everywhere. "Support" = patients the method may fit on; "query" = held-out patients it is scored on. "Gain" = held-out R² of a relation model minus held-out R² of a stated baseline model, both on query patients. B_nuis / B_known / B_decomp are the three baselines defined in Section 3.4. A "cell" in the blind runs is one target × one fold job, never a biological cell.

## 1. The arc in one page

MORPHEUS set out as a system that turns paired histology and spatial molecular measurements into reproducible scientific relationships. It went through six methodological versions in four months. The through-line is one question that sharpened each time: *what is the learned component actually contributing beyond what a careful classical pipeline on frozen foundation-model features already gives?*

| Period | Version | Learned component | Why it was replaced |
|---|---|---|---|
| Jul 2026 | v1 "query-former" multimodal encoder | joint H&E + ST encoder trained to predict expression | prediction alone is a crowded, subsumed contribution; no discovery object |
| Aug 2026 | TF-SC + morphological map of the 41 Gavish programmes; dual-view discovery; clinical sidecar | none in the method (training-free calibration on frozen H-Optimus-0); discovery via residual programmes + tissue dictionaries | the programmes are known biology; morphology–programme links were absorbed by composition; clinical arm admitted nothing (α = 0) |
| late Aug – mid Sep | CSCD / DISCO (ε coupling budget, certified discovery) → Scientific Discovery Foundation Model (replication-grounded encoder + hypothesis compiler + dbench) | encoder trained so that its code makes planted objects discoverable | the encoder never reached parity with an oracle code under any conventional objective (step-4 gate failed three times); the benchmark grammar was written by us; scope spanned every science |
| mid – late Sep | real-substrate general discovery stack (H = (S, C, f, E)); factorized contextual objective vs SSL / predictive arms; renal prospective campaign v0.1–v0.3 | response-free contextual latent prediction on top of frozen features | beat SSL on a narrow controlled metric but never beat frozen source features on real targets; the five "leads" of v0.3 were an artefact of an uncentred competitor |
| 10 – 15 Oct | measurement bank with frozen FMs + target-conditioned residual hypothesis generator; kidney v0.4/v0.5 blind re-runs; CPTAC tissue→patient; BMMC CITE-seq; nested explanation ladder; relation v06; method benchmark | sparse-gated residual interaction network nominating variable sets | EBM beat the generator on planted products; every replicated biomarker was linear and single-variable; owner: method claims must be structural, not plumbing |
| 15 – 22 Oct | **learned relation search** v01 → v02 → **v03 (current)** | dataset-conditioned network that decides which variable sets are worth fitting, meta-trained across HEST studies | v01 matched a support-only screen and became a classifier of our own generator; v02 could learn support fit as a shortcut; v03 predicts *shrinkage* of support gain on held-out patients and is the frozen method |

What never changed: public data only; patient-disjoint replication; structured nulls; registered, hashed protocols before any blind run; literature closed until hypotheses are frozen; H-Optimus-0 as the only pathology foundation model; receipts for every claim.

## 2. History: what we built, why, and why we moved on

### 2.1 July 2026 — the first multimodal encoder ("v1 query-former")

The earliest MORPHEUS was a joint H&E + spatial-transcriptomics encoder (query-former variants, `morpheus/outputs/v1_*`) whose job was to predict molecular state from tissue images. Its checkpoints and results are archived; nothing from it enters the paper. It was abandoned when the owner's review (2026-08-19, `translational.md`) established that a per-region programme heatmap predicted from H&E is **subsumed** by existing work: GHIST, SciSt and Path2Space (virtual spatial transcriptomics), PathPrism (interpretable spatial biomarkers), HistoAtlas/PICASSO (pan-cancer morphology atlases), MINT/SEAL (molecular fine-tuning of pathology foundation models). Prediction was not a contribution. The project needed a *discovery object*.

### 2.2 August 2026 — TF-SC, the morphological map, dual-view discovery, and the clinical sidecar

**TF-SC (training-free spatial calibration).** Instead of training an encoder, we took frozen pathology foundation-model spot embeddings (H-Optimus-0 primarily; UNI, Virchow and others benchmarked) and predicted spot-level gene expression with a fixed ridge stage S, a neighbourhood (spatial) stage, and a gene-covariance stage G chosen by inner cross-validation on training slides only. On the HEST-bench prediction tasks TF-SC v1 reached Pearson 0.431 on H-Optimus-0, competitive with the in-house-reproduced state of the art (STFlow, STPath) and improving every backbone tested. One revision (v2) was allowed, pre-declared and capped: it changed only the selection rule after a measured defect on two few-slide tasks (IDC, PAAD). The method's purpose in the programme was to be the *scaling* engine (H&E-only deployment of a spatial state), never the discovery engine. A binding rule was set then and still holds: **discovery runs on measured spatial transcriptomics, never on predicted expression**, otherwise we explain our own model's artefacts.

**The morphological map of the 41 Gavish meta-programmes.** The science framing was "molecularly supervised morphological phenotyping": for each of the 41 pan-cancer malignant programmes (known, named biology such as Hypoxia, EMT-I, Interferon/MHC-II, Metal-response), which tissue phenotype constitutes it once composition is held fixed? This spawned seven workstreams: MP39 characterisation; MMD (composition-matched pairs → descriptor bank → minimal stable set → ablation battery); RPD (residual programmes: regress the 41 known programmes, composition, cancer type and batch out of measured ST and factor the residual into unnamed candidates); TF-SC external cohorts; TF-SC test-time compute; a replication grid (7 routes, 18/45 same-cancer rows replicated); and characterisation v4. A cross-workstream finding worth keeping: **depth confounding produced false negatives as well as false positives** (the matched-random band was inflated by sequencing depth; correcting it moved MP1/PRAD from not-evaluable to replicated).

**Dual-view discovery (Phases 1–3, 2026-08-21 → 08-24).** Molecular states (20 residual programmes per cohort, ccRCC and brain) and tissue states (CellViT-based composition, graph, boundary and mesoscale dictionaries; a tissue-only cross-scale segmentation) were discovered *independently*, frozen, and only then matched on held-out patients. Of 160 locked programme × tissue-state pairs, five were held-out supported and three context-specific (e.g. ccRCC G18–T01 −0.140 [−0.227, −0.058]; G11–T01 +0.165 [0.083, 0.256]). After a fixed composition/graph/boundary adjustment only G11 retained a positive adjusted interval. Phase 2B (200-row direct-scale matrix) supported no row; Phase 3 found every candidate **non-selective**: no single representation block exceeded a count-matched disruption reference, partly because the five tissue blocks shared 39 of 98 columns. G18 (a complement/antibody vs EMT axis) survived as the one legacy ccRCC lead and was carried forward as a test case for later machinery; it is not a paper result.

**The clinical sidecar (Track B and the spatial-organisation arm).** Two independent clinical arms fed auxiliary molecular features into an α-gated residual sidecar on top of the frozen H-Optimus-0 TCGA baseline. Both returned structural nulls: α = 0 in ~90 % of 574 cells (mean programme levels) and 848/855 cells (variance / entropy / Moran's I / assortativity of a TF-SC-calibrated field), predictions bit-identical to baseline. The lesson recorded was that the frozen baseline is strong enough on TCGA that an honest selector admits nothing, so the binding constraint was the admission architecture and substrate, not the feature family; and that endpoint selection had been premature (discover → characterise → mechanism → *then* pick the endpoint).

**Why we moved on.** The 41 programmes are known biology, so the only defensible discovery claim was "a previously unknown tissue manifestation of a known programme", and the dual-view results showed those manifestations were largely composition. Prediction was crowded, the clinical arm was null by construction, and the residual-programme route had a direct novelty threat (RESCUE, Nat Comms 2026, already separates canonical from residual programmes; a 2026 cNMF paper predicts programmes from morphology). The owner asked for a general discovery method whose learned component does something a classical pipeline cannot.

### 2.3 Late August – mid September — CSCD/DISCO, then the Scientific Discovery Foundation Model

**CSCD (certified sparse cross-modal discovery).** The thesis: every self-supervised objective optimises representation quality; nobody optimises for discovery yield. A joint cross-modal objective can *manufacture* correspondences (the "modality split" literature), and the field has no quantity separating evidentiary from artefactual findings. CSCD introduced an ε coupling budget bounding how much cross-modal structure the objective may create, adversarial residualisation (representation about the unexplained), conjunctive search, and conformal/PPI certification; the planned headline was a false-correspondence-rate vs true-discovery-rate frontier. ε was measured (exact on marginal coupling, compressed ~12× on conjunctive coupling, strictly monotone) but never applied at a selected operating point to make a certified discovery.

**The Scientific Discovery Foundation Model (SDFM) and the eight headlines (2026-09-06).** The ambition widened: *can a representation be trained so that scientifically meaningful objects become discoverable, across sciences, rather than merely reconstructed or predicted?* The training paradigm was named replication-grounded scientific object learning (θ* = argmax independently replicated discoveries enabled by f_θ); the architecture was a shared scientific-object encoder with learnable object slots, entmax modality gates and a mixture of discovery experts; a typed hypothesis compiler turned codes into claims (AND / XOR / threshold / lag / spatial compositions); a controlled benchmark (`dbench`) planted objects into real substrates (biology, climate, materials, physics); and a bank of specialists (cNMF, interaction detectors, SINDy, symmetry methods) set the bar. Eight headlines were written down with formal bars, the first being the kill-or-win test: *replication-grounded training yields more replicated discoveries than reconstruction, SSL, prediction or random at matched architecture, data, compute and search budget.*

**What happened.** The instrument-validity → positive-control → architecture-parity → objective test → OOD → real-science protocol was applied strictly. The architecture-parity step ("step 4") **failed three times**: under reconstruction training the encoder's slots never approached an oracle code's discovery score (an oracle code at the model's own 75 % sparsity scored 0.815 vs the best specialist 0.603, so the architecture *could* express parity), and reconstruction loss kept falling while agreement with planted latents peaked early and decayed. The owner's ruling: step 6 (the objective comparison) was non-evaluable, not negative, until step 4 passed; a step-4 failure with a working instrument is an architecture failure. In parallel, the theory work corrected the spec's objective (the declared null-rate constraint was mathematically infeasible at its stated temperature; a derived scaling law fixed it), the compiler was found 3× redundant in its gate stream and unable to form `own × LAG(partner)` shapes, and the specialist bank turned out not to contain the named methods. The decisive argument against continuing was recorded in `REAL_STREAM_DECISION.md`: the benchmark's hard compositions were shapes *we* planted, so a typed enumeration stream tuned to them would make the compositional-OOD claim circular exactly where it could least afford it.

**LOCKIN → LOCKINv2 → trainprotocol+more (2026-09-10 → 09-18).** The operating doctrine was reset twice: tests, not gates; a neutral result triggers the next mechanistic design, not a narrower paper; ≤ 3 agents; MORPHEUS-from-random vs SSL-from-random remains the primary paradigm test, SSL+MORPHEUS is secondary; capability frontier (HardSolveRate, object fidelity) beside average discovery count. The 2026-09-18 plan then narrowed the substrate: **real data by default**, controlled perturbations of real data only as calibration, foundation models as a common frozen observation layer (not SSL pretraining), and a biological flagship on paired H&E + spatial transcriptomics with a four-level evidence hierarchy (controlled real-substrate calibration → patient-held-out recurrence → external/orthogonal support → intervention).

**Why we moved on.** The SDFM programme had produced a large amount of measurement infrastructure (ResultRecord, matched flag budgets, FCR/FDR reporting, dual nulls) and a clear negative on the encoder, but no discovery and no learned advantage. The owner's claim map (2026-09-16) was explicit: audits never make the paper; what was missing was (1) a genuine learned advantage over SSL, (2) a real validated discovery, (3) an agent augmentation result.

### 2.4 Mid – late September — the general discovery stack and the renal prospective campaign

**Design (discoadd.md, 2026-09-25).** A scientific object is H = (S, C, f, E): a sparse variable set or subspace S, optional context C, a flexible relation f of unrestricted form under capacity control, and the environments E where it holds. No predefined operators (AND/XOR/threshold are *descriptions* of a validated object, not the universe of objects). The shared stack: `DiscoveryEpisode → RepresentationProvider → plural proposal → candidate freeze/hash → flexible relation fit against the best simpler competitor → independent (patient-disjoint) validation → structured nulls → optional compression → receipt`. ## 3. The current method: learned relation search v03

Everything in this section is implemented in `~/morpheus_work_v06` (`morpheus_encoder/learned_search/`, `morpheus/tier2/substrates/hest_multi.py`, `dbench/harness/`, `dbench/downstream/`, `dbench/protocols/`) and is governed by `.claude/morpheus_training_and_evaluation_spec.md` and the "MORPHEUS Downstream" protocol appended to `.claude/learned_search_v02.md`. Every object is one of three kinds: **fixed** (a deterministic procedure, run once per cohort, no learned parameters), **trained** (gradient descent), or **evaluated** (a measurement). There is exactly one trained object.

### 3.1 The problem the method solves

Given one paired H&E + spatial-transcriptomics cohort, a target variable (a gene, a programme score, a residual molecular programme, or a morphology coordinate), and the cohort's *support* patients, propose a small ranked list of **variable sets** (1–4 variables, each in one of four spatial versions, drawn from molecular, morphological and spatial-context vocabularies) such that a flexible relation fitted on the support patients to each set **replicates on new patients**: it keeps a positive held-out gain over the stated baseline on query patients, and, for sets of size ≥ 2, keeps a positive higher-order gain over its best proper-subset decomposition. The budget is the number of sets whose relation we are allowed to refit (K = 64). The hard part is not fitting relations — a closed-form kernel ridge does that — but deciding, from the support patients alone, *which of ~10⁶ possible sets are worth fitting*, because support fit is a poor guide: on the development targets ≈ 80 % of what fits the support patients replicates, so the method has to be right about the remaining 20 % without harming the rest, and in few-patient, new-study or new-organ regimes the gap between support fit and held-out gain widens.

### 3.2 Data unit and partitions (fixed)

A **spot** carries its H&E patch, gene counts, 2-D coordinates, section, patient, study, platform (legacy ST 100 µm vs Visium 55 µm) and organ. A **study** is one source publication/cohort as catalogued in HEST or in our manifests. Studies are assigned once, by a signed, hashed manifest (`dbench/protocols/sprint_partitions_v01.json`, revision 2, sha256 `06301b22…`), to exactly one of four partitions:

| Partition | Studies | Sections / patients | Use |
|---|---|---|---|
| Meta-training | He 2020 breast IDC (legacy ST, Ensembl ids), Andersson 2021 HER2+ (legacy ST), lymph-node IDC, bladder (2 studies), HCC TREM1, 10x demonstration samples pooled per organ | 136 / 59 | train the gain predictor; build the morphology dictionary |
| Development | kidney injury (non-cancer Visium) | 23 / 22 | hyper-parameters, checkpoint selection, every open design choice; never training |
| Historical rediscovery | Ji 2020 cutaneous SCC (ST + 4 Visium sections), Valdeolivas 2024 colorectal (Visium), Kiviaho 2024 prostate (Visium, expression + spatial only) | 76 / 59 | published finding written down and hashed before any output is inspected |
| Blind discovery | Meylan 2022 ccRCC (24/24), PFA ependymoma (14/11) | 38 / 35 | registered runs; untouched by training, development and dictionary construction |
| External replication (ccRCC) | Li 2022 (Mendeley, 16/8, fresh-frozen), GSE250163 (5/5, FFPE), Zenodo 14620362 (3/3, FFPE, 0.66 µm/px image) | 24 / 16 | opened only at the replication step |

Within meta-training, one whole organ (bladder, 6 patients) is withheld as the **organ transfer holdout**; no platform holdout is possible inside meta-training (only two platform groups), so platform transfer is evaluated on Ji 2020 (ST and Visium sections of the same patients) and on FF→FFPE external ccRCC cohorts. Spots from one patient never appear on both sides of any support/query or discovery/evaluation boundary. The historical studies carry `previously_influenced_morpheus: false` with evidence (the only prior contact was an embedding-only pass in August).

### 3.3 Fixed inputs

**Nuisance model N.** Ridge regression of the target on log total counts, one-hot study, one-hot platform and per-patient intercepts, fitted on support rows only. Every gain is measured relative to a baseline containing at least N; nothing is ever credited for explaining depth, study, platform or patient mean.

**Molecular variables (RNA only).** (1) log(1 + counts per 10,000) for every gene; (2) 512–1,024 highly variable genes selected by dispersion on support patients, per fold, gene identity retained; (3) fixed programme scores: 50 MSigDB Hallmark sets and the 41 Gavish meta-programmes, scored per spot as the mean standardised expression of member genes — these are **known-biology covariates and also candidates**; (4) **residual molecular programmes**: regress log expression on depth, three composition variables and the Gavish scores by ridge with donor-grouped inner CV, truncated SVD of the residual, rank by 50-permutation parallel analysis, loadings aligned across folds by cosine assignment; cached per study. No image information enters any of this.

**Morphology variables (image only).** (1) The frozen H-Optimus-0 spot embedding (1536-d) exactly as produced by the backbone; no layer is trained on it, no gradient reaches it. (2) **Morphology dictionary**: embeddings standardised per study (mean, sd per dimension), k-means with k = 64 run once on the pooled standardised embeddings of all meta-training spots (170,259 spots); a centre is kept only if populated by spots from ≥ 3 meta-training studies, which guards against centres that encode study identity — **33 of 64 centres survive**. A spot's 33 morphology similarities are cosine similarities to the centres; a new cohort's standardisation statistics come from its support spots. Centres are interpreted after the fact by their nearest patches. (3) CellViT nuclear descriptors where segmentations exist (nuclear density, area, eccentricity, solidity, PanNuke class fractions over the spot footprint). No RNA information enters any of this. The two dictionaries are built from one modality each and frozen before any search; **the search is the only component that sees both modalities.**

**Spatial versions.** Every scalar variable v exists in exactly four versions: own value v₀; mean over the 6 nearest same-section neighbours v₆; mean over the 18 nearest v₁₈ (two-hop ring for legacy grids); contrast v₀ − v₆. Neighbours are Euclidean on section coordinates and never cross sections. A **candidate** is one (variable, version) pair; a **set** S is 1–4 candidates; a **target** is one variable in its own version. Composition is CellViT PanNuke fractions (neoplastic, inflammatory, connective) where every section has a segmentation (Meylan, ependymoma, kidney injury) and programme principal axes otherwise (Ji, Valdeolivas, Kiviaho, external ccRCC); the source is recorded per cohort.

**Target-leak exclusions (fixed).** For programme targets, the target's own score, every programme with gene-set overlap coefficient ≥ 0.2 to it, and its member genes as single-gene candidates are removed from the pool; for gene targets, every programme containing the gene; any column with within-patient |r| ≥ 0.9 to the target is removed. The exclusion report is stored per episode.

### 3.4 Relation family, gains and the three baselines (fixed)

For a set S the relation f_S is kernel ridge regression on **256 random Fourier features** of the candidates in S (Gaussian kernel, bandwidth by the median heuristic on support) plus linear terms in those candidates plus the nuisance model N, solved in closed form on support rows; the ridge penalty is chosen on a fixed grid by leave-one-patient-out (LOPO) over support patients; solves are batched on the GPU in float64 with a jitter retry. **Proper-subset decompositions** of S are fitted in the same family (each proper subset with its own joint RFF map; singletons on the per-variable map), 1 / 4 / 14 decompositions for k = 2 / 3 / 4.

Three baselines are declared, and every gain names its baseline:

- **B_nuis** = N. General gain G = R²_query(f_S + N) − R²_query(N). Answers "does this set predict the target on new patients beyond nuisance?"
- **B_known** = N + the known programme scores (91) + composition, **excluding the target programme and every overlapping programme** (overlap coefficient ≥ 0.2 on the scoring panel) for programme targets and every programme containing the gene for gene targets; residual-programme and morphology targets drop nothing. Answers "beyond known biology?" This definition is the single source for labels, pool scores and receipts (`relation_v03.baseline_for`), after a defect (the target inside its own baseline) was fixed at the source on 2026-10-21 (commit b7879b1).
- **B_decomp** = the best proper-subset decomposition of S. Higher-order gain **G_HO = R²_query(f_S) − max over decompositions R²_query(f_decomp)**, with the maximum taken *inside* each bootstrap draw. Answers "is the joint structure needed, or do the parts suffice additively?" A set is flagged **higher_order** when the G_HO patient-bootstrap CI lower bound > 0 *and* the full model's held-out R² > 0. On purely additive truth G_HO is slightly negative (−0.008 to −0.002), because a joint map approximates an additive function less efficiently than per-variable maps at equal feature count — a cautious direction, recorded as a plumbing fact.

Patient bootstrap (resampling query patients) gives every gain a 95 % interval; "replicates" means the interval excludes zero.

### 3.5 The one trained object: the shrinkage predictor g_θ

**What it predicts.** Not held-out gain directly (v02's shortcut), but the **shrinkage** Δ = G_sup − G(L): how much the support-fit gain of a set will fall when the relation is scored on held-out patients at transfer level L. The support gain G_sup is observable at proposal time; Δ is what the network adds. The network is conditioned on the declared baseline B ∈ {B_nuis, B_known, B_decomp} (an embedding added to every token; `model_v03.encode` adds `b_emb.weight[BASELINES.index(B)]`) and on the transfer level L ∈ {L0 new patients of the same study; L1 new study, same platform; L2 new platform; L3 new organ — evaluation only, never trained}.

**Inputs per candidate (identity-free).** A DeepSets pooling over up to 256 sampled support spots of (candidate value, target value, their product, patient and neighbourhood context) concatenated with **eleven fixed transfer diagnostics** computed on support only: leave-one-patient-out fit variance, within- vs between-patient association share (from raw per-patient means), Moran's I of the candidate and of the target, correlations with depth and with the three composition variables, support CV gain of the single, and the B/L codes. No gene name, programme name or centre index reaches the network, so it cannot memorise identities across studies.

**Body.** A 4-block pre-norm Set Transformer (d = 192, 6 heads, scaled-dot-product attention, never materialising L × L) over all candidate summaries, so each candidate's prediction is conditioned on the others in the pool. About 2 M parameters.

**Heads.** A Gaussian head (mean and sd of Δ) for singles; a **rank-32 bilinear pair head** predicting pair shrinkage and pair support gain from the two constituents' tokens. There are no triple or quad heads: triples and quads are scored from their constituent pairs before fitting.

**Labels.** For sampled support/query episodes, every labelled single and pair gets (G_sup, G(L) averaged over three query draws, Δ) by the fixed relation family under the episode's B. Labels are drawn 48 uniform singles + 48 uniform pairs, 16 + 16 on-policy (from the current beam), 16 failure-mode pairs (strong support, weak expected transfer). Planted sets are **never** labels. Labels are cached per episode (19,753 files) and shared with the evaluation harness; non-finite labels (near-constant candidates) are masked.

**Loss.** Gaussian negative log-likelihood on Δ + squared error on pair support gain + top-weighted ListMLE over the episode's labelled sets (ranking by realised held-out gain). No teacher forcing, no planted-variable or family labels anywhere.

**Episodes.** Drawn from meta-training studies; 3–10 support patients × ≤ 600 rows per patient; support and query **patient-disjoint** (the row-split ablation samples support and query rows from the same patients); targets from both modalities (molecular targets with all candidates; morphology targets with molecular + context candidates); controlled episodes (planted relations from the generator families on the cross-fitted residual, fraction of residual variance log-uniform on [0.005, 0.20]) pass through the same loss as extra episodes only; held-out generator families are never trained on. 64-episode replay buffer, 8 episodes per step, one new episode per step.

**Search at proposal time.** Candidates are the full pool for the target (≈ 1,556 singles on kidney injury). Singles are scored by predicted held-out gain (G_sup − μ_Δ); the top singles seed pairs scored by the pair head; triples and quads are composed greedily inside a beam and scored by their constituent pairs; a lower-confidence-bound beam (κ·σ_Δ) keeps K = 64 sets (default split 26 singles, 26 pairs, 8 triples, 4 quads). The 64 sets are then **refitted in closed form on support** and the final list is **ordered by support gain** (this ordering was adopted into the method on 2026-10-21; the LCB ordering remains as an opt-in variant). The output per set is the fitted relation, its support gain, predicted shrinkage (mean, sd) and, after validation, held-out gains under the three baselines with CIs and the best decomposition.

**Checkpoint selection.** Every 1,000 steps the harness scores the search on 40 fixed development targets × 3 patient-grouped folds (targets sha 551f57ff…) under B_nuis with two null targets (within-study patient permutation; identity scramble); the selection statistic is *net yield at k = 10* (replicating sets among the top 10 minus the null rate). Calibration (Spearman of predicted vs realised gain, ECE) is logged. This statistic is internal and is never reported as a result.

**Training and freeze.** Two 20,000-step runs on the A100 (full = patient-disjoint episodes; row-split = ablation), AdamW 3e-4, 500-step warm-up, ~2.3 s/step. Full run frozen at step 13,000 (sha256 a5bab38e…, pre-repair record). Because B_known had been defined with the target inside it for 7.6 % of labelled episodes (programme targets) and over-strictly for 26 % (gene targets), a **repair** continued training from the frozen full checkpoint for 4,000 steps under the fixed definition (fresh AdamW, lr 1e-4, 200 warm-up, cosine), with a B_known calibration readout before and after. Selected repair step 1,000 by the unchanged rule. **Release checkpoint:** `runs/development/learned_search_v03/release/frozen.pt`, sha256 `13c36faa8cd9caa7121381b59dc06e5d35069492b565e1fa786e2e03a46f3446`. B_known calibration Spearman 0.878 → 0.858, mean error +0.097 → +0.023 (the base over-predicted B_known gains by ≈ 0.1 R², as degenerate labels would produce); B_nuis development yield 6.89 → 7.21. Accepted without retrain. The row-split ablation is frozen at step 4,000 (sha c8da7d74…); its repair ran out of GPU memory and is marked NOT_FROZEN pending a rerun. The label cache has since been relabelled under the fixed definition (7,684/7,684 real entries).

### 3.6 Baselines and matched budgets

Every comparison method receives the same support rows, the same candidate pool, the same relation family for scoring, and reports `n_relationships_tested`. Named methods: **EBM** (explainable boosting machine, GA2M, interpret-core), **gradient boosting + Friedman's H**, **RuleFit** (scikit-learn reimplementation after imodels 3.0.4 segfaulted; labelled as such), **PySR** symbolic regression (Julia; on a 256-candidate interaction-aware shortlist), **TabPFN-v2 + SPEX** (attempted; segfaults on every historical task and was recorded as did-not-complete), **linear interaction screen** (lasso on mains + pairwise products of the top marginal variables, patient-grouped CV), **neural interaction detection (NID)**, a **MISTy-style multi-view random forest** (scikit-learn reimplementation), and **count-matched random selection**. Each method scores every pool member with its own importance (EBM term importance; GBM partial-dependence spread / H; RuleFit summed rule importance; lasso |coefficient|; PySR Pareto-front frequency; NID first-layer interaction strength; random uniform). Internal controls that were once baselines (support-fit ranking, variance-penalised ranking, GBM-on-statistics) are **not reported**: a comparison with no room to improve on a sub-task outside the innovation is a tautology, and the support-fit ordering was adopted into the method.

### 3.7 Evaluation protocol (public-facing)

The method-independent task is **ranking candidate relations by whether they replicate on held-out patients**: the binary ground truth per set is whether its realised held-out gain (pooled over the folds' query patients, patient bootstrap) is above zero at the stated baseline. Metrics are standard retrieval metrics — AUROC, average precision, precision@k and recall@k on the registered top-k lists, hit@k / rank of first hit / MRR for published findings — with 95 % bootstrap intervals over targets. ## 5. Design considerations and the reasons behind them

This section records *why* the current method looks the way it does. Each item names the alternative that was tried or considered and the evidence that decided it.

**5.1 Learn the search, not the representation.** Three generations of learned representations (joint query-former; replication-grounded slot encoder; factorized contextual latent prediction) lost to frozen source or foundation-model features on every real target. The measurement showed where the loss came from: a learned code *destroys information* useful for discovery (accessibility 0.38–0.51 vs 0.72–0.77 for predictive/legacy arms) while minimising its own loss. So the representation is now a *protected bank* of fixed, interpretable measurements, and the only learned object decides what to test.

**5.2 Decouple the two modalities until the search.** A joint cross-modal objective can manufacture correspondences (the CSCD motivation). The molecular dictionary is built from RNA alone, the morphology dictionary from images alone, both frozen before any search; the search is the only place both are seen. This is also why the owner rejected a learned 64-concept projection on H-Optimus-0 in favour of cosine similarities to k-means centres fitted once: a trained projection is a learned alignment by another name.

**5.3 Identity-free inputs.** Gene names, programme names and centre indices never reach the network; it sees only per-candidate statistics and pooled support observations. A network that saw identities would memorise study-specific signatures across the meta-training studies and could not claim to transfer. The same reason puts whole *studies*, not random spots, on the partition boundaries.

**5.4 Predict shrinkage, not gain; order by support fit.** v02's network could learn support fit as a shortcut (synthetic Spearman 0.46 at 300 steps with sets of size 3.8/4). The v03 target Δ = G_sup − G(L) removes the shortcut: support gain is an *input*, and what the network must add is how much of it will survive on new patients. The LCB re-rank by predicted shrinkage then turned out to *hurt* on the development targets (−0.3 to −0.5 net yield per checkpoint; AUROC 0.508 vs 0.859 under support ordering), while the network's *beam* (which sets get fitted) already beat the support-fit control's sets (7.1–7.2 vs 6.9 under identical ordering). The owner's rule — adopt what beats us on a sub-task outside the innovation — made support ordering part of the method and removed the re-rank comparison from the tables.

**5.5 Patient-disjoint episodes, with row-split as the ablation.** The row-split network (support and query from the same patients) scored slightly higher on the one-organ development metric, which is the signature of deviating least from support fit. The patient-disjoint network is the method because the claim is about new patients; the ablation stays as the paper's Q2 comparison.

**5.6 Three baselines, reported never gated.** Earlier versions gated on one competitor and lost findings twice — once to an uncentred competitor that made artefacts look like discoveries (v0.3's five leads), once to a competitor containing the response (v0.2). The current design declares B_nuis, B_known, B_decomp, conditions the network on which one is in force, reports all three gains per row, and gates only on the registered pass rule. The known-biology baseline needs its exclusion rule (target and overlapping programmes removed) or it absorbs every programme target by construction — found and fixed on 2026-10-21, with a continued-training repair rather than a retrain because only the known-conditioned head was affected.

**5.7 Higher-order gain against the best proper-subset decomposition in the same function family.** "Beyond additive" is cheap to claim against a linear additive model. G_HO compares the joint RFF fit with the *best* additive-of-subsets RFF fit (all 1/4/14 decompositions), with the maximum taken inside each bootstrap draw, and requires the full model's held-out R² > 0. On the kidney smoke this flag removed 12 of 32 "higher-order" rows whose models sat below the held-out mean.

**5.8 Fixed relation family, closed form, GPU-batched.** A random-Fourier-feature kernel ridge with linear terms and LOPO penalty selection is flexible enough for smooth, threshold-like and interaction shapes, is deterministic given the seed, refits in closed form (so the outer loss of the search is the query error of a genuinely refit relation), and batches on the GPU (validation 575 s → 12–18 s per cell). The alternative — separate ridge penalties for the comparison block and the hypothesis block (relation v06) — removed a detection floor in the previous method but is plumbing; v03_rff carries its own penalty selection and the three-baseline decomposition.

**5.9 Named, standard baselines on a shared pool with their own importances; no in-house competitors.** Owner directive of 2026-10-21: in-house metrics (net yield, "the screen") and in-house competitors are unrecognisable to a reader; the paper reports AUROC / AP / P@k / hit@k / MRR against EBM, GBM + Friedman's H, RuleFit, PySR, TabPFN + SPEX, a linear interaction screen, NID, a MISTy-style forest and random, each scoring every pool member by its own importance so that AUROC is a proper retrieval metric rather than an artefact of each method ordering only its own 64 sets (the first table had AUROC ≈ 0.5 for everyone for exactly that reason).

**5.10 Development-only method changes; evaluation changes only when they generalise.** The hit rule of the historical protocol was changed once (v01 → v02) because no column could reach the v01 threshold on two tasks, and the change was hashed before the learned column ran and applied by re-scoring the saved baseline lists. The list-construction change now under way (anchor cap / known-conditioning) is chosen on the development set and reported beside the locked version-1 historical lists. Controlled-world fractions were extended *upward* only to complete a detection curve that was zero for every method.

## 8. The five phenomena: problem definitions, MORPHEUS formulation, downstream suite, metrics and figures

The scientific framing, literature and honesty notes for each problem are in the owner-facing document "MORPHEUS Second-Wave Discovery Programme" (2026-10-22). This section consolidates, per problem, how the problem is posed as a MORPHEUS object, how the registered pipeline answers it, what downstream clinical and translational analyses follow, and exactly which metrics and figures are produced. Everything shared across problems is stated once in 8.0.

### 8.0 Shared across all five

**Object shape.** A target state in one tissue compartment, explained by a configuration of 1–4 variables drawn from own-spot programmes and genes, neighbourhood (6- and 18-neighbour) programmes and genes, own-minus-neighbourhood contrasts, CellViT composition fractions and the 33 frozen morphology coordinates. The configuration must (i) add to the nuisance model (B_nuis), (ii) add to known biology (B_known: every programme and composition minus those overlapping the target), (iii) for |S| ≥ 2, beat its own best additive decomposition in the same function family (G_HO at B_decomp), and (iv) replicate on held-out patients and, where cohorts exist, on independent cohorts. (iii) is reported, never gated; the paper's object count is the B_known column with the higher-order subset marked.

**Pipeline per problem.** Registered, hashed protocol (checkpoint 13c36faa…) → 5 patient-grouped folds → learned search (K = 64) and classical proposers (EBM, GBM) on identical designs in every cell, merged by interleaved rank → relation v03_rff refit on support, scored on query → three nulls (spatial block, within-patient permutation, interaction break; 199 draws) → fold pass (held-out R² > 0, gain LB > 0, permutation p ≤ 0.05) → cross-fold scoring of every frozen set in every fold → finding pass (≥ 3/5 folds, mean gain ≥ 0.01, all nulls in every passing fold, BH q ≤ 0.10 within family) → four non-gating counts per family → external replication v03 (frozen variables and constants, no refit) → characterisation → literature lock and novelty grading.

**Head-to-head inside every problem.** Because the classical proposers run on the same data in every cell, each problem yields three counts: objects found by the learned search only, by EBM/GBM only, and by both, at each baseline. This is the method claim inside the biology.

**Shared metrics (every problem, every family).** Per cohort and family: n frozen; passes at B_nuis / B_known / B_decomp / B_known ∧ B_decomp; higher-order counts by set size (2/3/4); learned-only / classical-only / overlap counts; external replication pass count per cohort; per finding: gain and CI at each baseline, G_HO and CI, best decomposition, passing folds, worst null p, q. **Shared figures.** (F0a) the four-count bar per family and cohort with the higher-order subset hatched; (F0b) proposer Venn (learned / classical / both) per cohort; (F0c) for each headline finding a three-panel: H&E thumbnails of top and bottom deciles of the fitted response, the spatial map of the response on one section, and the fitted response surface (2-D for pairs; conditional slices for triples/quads) with patient-bootstrap bands.

### 8.2 Problem 2 — the invisible field

**Problem.** Which configuration of molecular and neighbourhood states marks histologically normal epithelium near a tumour as molecularly abnormal, how does it depend on distance, in which contexts does it fail to appear, and is it absent in healthy tissue?

### 8.4 Problem 4 — conditional inversion of immune signals

**Problem.** For an immune programme that explains a target state, does the sign of its effect reverse as a continuous function of its neighbourhood, where is the crossing point, and does the rule replicate?

**MORPHEUS formulation.** Not a new search: a declared characterisation test (`inversion_v03`) applied to every passing context-conditioned relation whose explanatory set contains an immune programme or gene at own-spot level and a neighbourhood term. The fitted relation is refit on fit patients; the partial slope of the target with respect to the own immune term is taken by central difference and averaged within the lower and upper within-patient tertiles of the context term; patient-bootstrap CIs on both slopes; **inversion** = opposite signs with both CIs excluding zero (Gail–Simon qualitative interaction); **same-sign modulation** = slope-difference CI excludes zero AND the joint relation beats the additive control on support gain AND ≥ 20 % slope change; otherwise **additive**. Crossing point located on a 19-point quantile curve with an interval, never assumed at the median. LOPO sign stability of both slopes. Matched nulls: the same procedure on permuted programmes and on spatially smoothed random programmes with matched Moran's I must not produce crossings. Cohorts: Meylan ccRCC (discovery; preview running on fold-level passes, re-run on the registered aggregate), replication of frozen rules in Li 2022 / GSE250163 / Zenodo.

**Downstream.** Replication of each rule with frozen variables and constants (slopes in both tertiles in the external cohort); characterisation of the immune term (effector / exhaustion / interferon / antigen presentation / plasma cell decoding) and of the context term (what neighbourhood it encodes; Squidpy enrichment); translational reading: the marginal components of each rule scored in the bulk treated cohorts we hold (CheckMate 009/010/025, JAVELIN Renal 101) with the stated limit that bulk data cannot carry the spatial condition; Open Targets for the immune axis; H&E student for the context term (is the neighbourhood condition readable from H&E?).

**Metrics.** Number of candidate relations; verdict counts (inversion / same-sign modulation / additive); per rule: lower- and upper-tertile slopes with CIs, crossing point with interval, LOPO sign-stability fraction, matched-null crossing rate; external replication of the sign pattern per cohort; bulk-cohort hazard ratios of the marginal components (reported as context-free, for contrast).

**Figures.** (F4a) for each inversion rule: target vs own immune term at low / mid / high neighbourhood level with bootstrap bands and the crossing point; (F4b) spatial map of the sign of the local slope on one section with H&E (where the biomarker means the opposite); (F4c) LOPO sign-stability strip; (F4d) replication: the same three slices in the external cohort.

### 8.5 Problem 5 — conserved rules across cancers

**Problem.** Do quantitative relations discovered in one organ (variables, constants, functional form) hold unchanged in others, and where do they stop?

**MORPHEUS formulation.** The replication step applied across organs (`transfer_v03`), i.e. external validation without refitting. Source relations: every finding passing B_known in a discovery cohort (Meylan first; CRC and cSCC after their aggregates; breast excluded as a source because the search model trained on it). Freeze: variable names, context transforms, fitted constants, commit hash. Re-test in each target organ with the same arithmetic by gene symbol, the shared morphology dictionary and rank-normal standardisation within section, under the target cohort's own nuisance model and runner folds: breast (He 2020, Andersson 2021), kidney (Meylan; kidney injury dev as a non-cancer control), colorectal (Valdeolivas), cSCC (Ji), prostate (Kiviaho; molecular relations only), ependymoma. Per cell: pooled gain with bootstrap CI, G_HO, sign agreement, calibration-in-the-large and slope; verdict replicates / sign-flips / no gain / not transferable (missing gene, no image). Nuisance check: transfer must fail on permuted and spatially smoothed random programmes with matched autocorrelation.

**Downstream.** The matrix itself is the result; for relations that transfer to ≥ 2 other organs: pan-organ characterisation (is the same cell-type context carrying it everywhere?), Open Targets / DepMap pan-cancer context, and the boundary map (organs where the sign flips or the gain vanishes) as the limit of a tumour-agnostic reading.

**Metrics.** Relation × organ matrix with pass / fail / not-testable; proportion of higher-order vs pairwise relations that transfer; number of relations transferring to ≥ 2 other organs; calibration slope distribution; matched-null transfer rate (must be ≈ 0).

**Figures.** (F5a) the relation × organ heatmap (gain with CI colour, hatched not-testable, sign-flip marked); (F5b) transfer rate by set size (1/2/3/4) and by family; (F5c) for the strongest conserved relation, the response surface in each organ on one panel; (F5d) calibration plot (observed vs predicted held-out gain per organ).

## 11. Neural set-composer redesign implementation (2026-10-24)

**Decision.** The v03 learned shrinkage predictor remains a negative ablation. It has direct heads for singles and pairs only; triples and quadruples are inherited from pair scores, so it cannot test the original compositional-search hypothesis in which individually weak molecular, morphology and spatial measurements become useful only as a complete tissue configuration. The redesigned neural object is therefore an **identity-free direct set composer**, not another final-ranker. Support-gain ordering remains the common post-refit ordering rule for every method.

**Implemented.** `morpheus_encoder/neural_set_composer.py` provides an identity-free patient-support encoder, direct order-invariant set decoder, set-level held-out-gain heads, and a bounded beam that writes legal sets of two through six variables. Candidate identity, gene/programme names and dictionary-centre identifiers cannot reach neural layers. Sets of size five or six require molecular, morphology and spatial/architecture roles, no role can occur more than twice, and alternate spatial spellings of the same base measurement cannot co-occur. `morpheus_encoder/composer_training.py` accepts only immutable patient-disjoint real-data episode labels with support/query receipt hashes; it refuses a non-disjoint episode. The loss uses realised held-out nuisance, known-biology and proper-subset gains of complete sets, plus order-rotated decoder supervision; it has no AND/XOR or planted-object label.

CLI validators in `dbench/scripts/` freeze a reviewed registry and evaluate ceiling receipts. Eight focused contract tests pass: direct legal composition, six-variable role coverage, identity isolation, patient-disjoint label enforcement, deterministic headroom, registry provenance, complete historical-object scoring and duplicate-object collapse.

**Not yet a result.** No composer has been trained and no primary task registry has been populated. The unit of replication is a patient, not a spot, section, task, or publication. When several tasks arise from one publication, primary uncertainty will resample source studies first and patients inside study second; 30 task rows cannot be presented as 30 independent biological cohorts.

**What a row must pass before it can be frozen.** (1) The source paper specifies a complete relation, context, or tissue configuration rather than only a cluster label. (2) Raw/processed measured spatial counts, coordinates, and registered H&E sufficient to reproduce the specified measurements are accessible under an allowed licence. (3) Patient identity supports a patient-disjoint support/query split with at least two query patients; studies with fewer than eight patients are retained only as secondary challenge tasks. (4) The source study, its derived embeddings, and every data artifact are absent from the project meta-training, development, historical, blind-discovery, dictionary-fitting, and hyperparameter-selection manifests. (5) The target and candidate construction can be written before running MORPHEUS, and the published answer can be operationalised without leaking its exact marker list into the search. (6) A modality adapter can read the data without substituting virtual/predicted expression for measured spatial data. Each row below is therefore marked **green** (documented public data and plausible patient split), **amber** (scientifically suitable but access/patient mapping/adapter still needs verification), or **red** (known project exposure; excluded). Green is not “frozen”: the exposure audit and exact target mapping are still mandatory.

**Why no pathologist review is needed for most rows.** The owner should review the biological statement for each eventual task: whether the hidden evaluator accurately represents the paper’s claim and whether the relation is sufficiently important to count as a rediscovery. The pathologist does not need to choose the molecular relation, inspect model outputs, or label the benchmark after results are known. **Higher-order evaluation redesign locked before execution (2026-10-31).** The common-pool best-of-64 endpoint is saturated: 60--63% of proposed rows are B_known-positive and 28--32% B_decomp-positive, so random lists almost always contain a positive row. It cannot decide higher-order discovery. Protocol `dbench/protocols/vnext_higher_order_retrieval_v01.json` therefore defines a separate diagnostic, with no new training labels: deterministic vocabulary-only banks of two-, three- and four-variable cross-modal, spatial-context and conditional-multiscale programs; all methods score every member before query data opens; a hidden evaluator labels only held-out programs that improve both B_known and the strongest proper-subset decomposition and pass patient-bootstrap, spatial-null and candidate-scramble controls. Primary outputs are B_decomp/AP and AUROC, precision/recall at K, exact-program and constituent recovery, and null-positive rate. The frozen current model is tested first. Any later training response may use only meta-training-study labels; the historical and blind cohorts stay untouched.
