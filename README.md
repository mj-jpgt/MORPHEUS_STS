# MORPHEUS code package

Code that produces the architecture, evaluations, tables and figures. Files are verbatim copies from the archived development clones; nothing was rewritten.
`PROVENANCE.tsv` gives, for every file, the package path, source clone, source path and sha256. `tests_static.log` and `SCRUB.md` record the static checks and the scrub.

## Environment

- Python 3.10+, one CUDA GPU for the learned search and the GPU-stage baselines. `pip install -r requirements.txt`.
- The code addresses its inputs and outputs by the original box paths and was not edited for this package:
  `~/morpheus_work_{bench,sw,v06,tx,v08}` (working roots, `runs/...` receipts are written below them) and
  `/lambda/nfs/geeg/biorag3_persistent_20260711` (`morpheus.tier2.substrates.hest_multi.STORE`, the data store).
  `scripts/00_env.sh` links the five working roots to this directory and, with `STORE_DIR=<path>`, links the store path to a downloaded copy of the dataset.
- Run everything from the package root with `PYTHONPATH` set to it (`scripts/_env.sh` does both).

### Figures

The figure scripts are verbatim and contain absolute Windows paths: `SCRATCH` (`plot_evidence_cards_v02.py`; the G3 scripts take it as `argv[1]`) must hold `cards/<id>/{spot_values.npz,<id>_heldout_int21.npz}`, `cards/p5_transfer_values.json`, `int21/{INT21_ds8.png,image_meta.json}`, `g3crop/`, `crc/`; `SKILL` (`plot_evidence_cards_v01.py`) must hold `export_figure.py` and `morpheus_style.py` (copies in `figures/_helpers/`).
`figures/fig6_evidence_cards/data/` holds the two small JSON inputs; `heldout_int21.py` produces the held-out state arrays from the characterisation context. Panel PNG/PDF outputs are not included.

## Known gaps

See the final lines of `tests_static.log`: files imported by packaged code that are absent from every archived clone (`dbench/translation_v10/relation.py`), and `morpheus_encoder/learned_search/tokens.py`, which was taken from outside the archive (`PROVENANCE.tsv`).
`morpheus/protocol/__init__.py` is deliberately not included: `dbench/object_cards.py` imports `morpheus.protocol.language` and falls back to loading `language.py` by path when the package import fails.
Freeze addenda (`runs/benchmark_v05/freeze_addendum_N.json`) are run outputs and are not in the archive; `dbench/benchmark_v05/addendum.py` writes them.


## Known dead import

`dbench/downstream/values_v06_eaca09b.py` line 266 lazily imports `dbench.translation_v10.relation`, a module that exists in no archived clone; `dbench/downstream/relation.py` defines the same `within_centre`. The import is only reached by a legacy code path and is left as is; no logic was rewritten in this package.
